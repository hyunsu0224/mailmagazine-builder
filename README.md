# メルマガ HTML ビルダー (Mail Template Builder)

table 基準のメールHTMLを、要素を組み立てるだけで作成できる単一ファイルのビルダー。
**サーバー不要** — `index.html` をブラウザでダブルクリックするだけで動きます。

## 使い方
1. `index.html` をブラウザでダブルクリックして開く
   - もしくはローカルサーバーで開く： `node server.js` → ブラウザで http://localhost:8787/
2. 左パレットから要素を追加 → 中央カードで内容を編集 → 右でリアルタイムプレビュー
3. 「⬇ HTMLダウンロード」で `mailmagazine.html` を出力（または「📋 コピー」でHTMLをコピー）

## 画像を複数並べる（共通トップ / MV / バナー）
- 各画像ブロックの「＋ 画像を追加」で、画像を**横並び**に配置できます
- 2枚以上のときは各画像に **幅(px)** を指定します
- 幅の合計がコンテンツ幅（既定750px）と合わないと警告が出ます：
  - 不足 → `⚠ 幅の長さが不足しています…余白(gap)を追加するか、幅を調整してください`
  - 超過 → `⚠ 幅が超過しています…幅を狭めてください`
  - 一致 → `✓ 幅ぴったりです`
- 「画像どうしの隙間 gap(px)」で画像間の余白も指定でき、合計幅に加算されます

## 用意されている要素
| グループ | 要素 | 内容 |
|---|---|---|
| 共通 | 共通トップ / 共通フッター | ヘッダー・フッター画像＋会社名/住所/配信停止リンク |
| 共通 | 更新日付 | 更新日テキスト（配置・色・サイズ） |
| 画像 | メインビジュアル(MV) / バナー画像 | 全幅画像＋リンク＋alt |
| 商品 | 商品ブロック | **2/3カラム切替**・「商品を追加」で自動的に下へ折り返し。画像/リンク/alt/商品名/価格/コメントを個別入力 |
| テキスト | バナー見出し＋説明文 / テキスト / ボタン(CTA) | 見出し・本文・CTAボタン |
| レイアウト | 区切り線 / 余白 | 線の色・太さ・線種、スペーサー高さ |

## 出力HTMLの特徴（メール互換ルール）
メールHTMLで避けるべきもの／守るべきものを踏まえて出力しています。

**使わないもの（メールで壊れる）**
- CSS `gap` / flexbox / grid / `position` などのモダンレイアウト → **一切不使用**
- 要素間の余白は CSS `gap` ではなく **スペーサー `<td>` セル（幅/高さ指定）** で表現
- `<head>` の `<style>` への依存 → レスポンシブ(@media)の“上乗せ”のみ。基本レイアウトは全て inline

**守っているもの**
- レイアウトは `<table role="presentation">` の入れ子 ＋ inline style
- 背景色は `style="background-color"` に加えて **`bgcolor` 属性を併記**（Outlook/Wordエンジン対策）
- 幅は `width` 属性 ＋ `style:width` を併記（`max-width` はOutlookでは無視されるため）
- 全体幅 **既定750px**・`align="center"` 中央寄せ・Outlook向け `<!--[if mso]>` 条件テーブル
- 画像は `display:block; width:100%; max-width; height:auto; border:0; -ms-interpolation-mode:bicubic`
- `@media (max-width)` で SP時に幅100%＋画像追従（プレビュー右上で PC/SP 切替可）
- 区切り線は `border-top` を当てた `<td>`（`<hr>` を使わない）
- リンク先URL・alt は各要素で自由に入力。未入力の画像には `main01.png` などの初期値が入る

> 補足：メールで「使えない」のは `<head>` の `<style>` 依存やモダンCSSであって、**インライン `style` 属性は各社クライアントで問題なく使えます**（本ツールの基本方針）。

## 保存/復元
- 編集内容はブラウザに自動保存（localStorage）
- 「💾 JSON」で設計を書き出し／「📂 読込」で復元 — 別PC・別案件へ持ち運び可能

## メモ
- 画像パス（`main01.png` 等）は出力後、実際の配信環境の絶対URL/相対パスに置換してください
- 出力HTMLは配信システムに合わせて文字コード（UTF-8）・件名等を調整
